# CSS Flexbox Cat Photo Gallery 🐱

This project is a **responsive photo gallery** created using **HTML and CSS Flexbox**, showcasing adorable cat images. It demonstrates the use of modern CSS layout techniques to build a clean and visually appealing gallery layout.

## 📸 Features

- Responsive image gallery using Flexbox
- Neat and consistent layout across devices
- Stylish header with accent color
- Hover-friendly, border-rounded images

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox)
